# GREEN DAWN — One-way Android Campaign (v0.8.0)

An original 16-bit-inspired jungle squad tactics game for Android, with tap-to-move and press-and-hold shooting, separated Alpha/Bravo squads and a growing permanent soldier roster.

## Install the new Android game

**[Download the Green Dawn v0.8 debug APK](https://github.com/MaviUK/Green-Dawn/releases/download/v0.8.0/GreenDawn-Campaign-v0.8-debug.apk)**

Open this link in **Chrome**, then find the downloaded file in **Samsung My Files → Downloads** and install it. This is an Android testing build, not a Google Play release.

**Important:** Debug APKs generated by GitHub Actions can use different signing certificates, so Android may refuse to install v0.8 over v0.7. Uninstall the older version if Android reports a signature conflict; uninstalling deletes its saved progress. Until we configure stable production signing, the career and memorial persist across app closes/restarts **within the same installation**, but cannot be guaranteed to survive uninstalling or changing debug signing keys.

## New soldier careers

- **Three starting recruits:** JAX, ACE and PIP; each has a lasting identity and rank, not a fresh squad at each level.
- **One promotion per successful mission:** RECRUIT → PRIVATE → LANCE CORPORAL → CORPORAL → SERGEANT and higher. Only living, deployed soldiers earn it.
- **Two new recruits after every victory:** New recruits join reserves; the strongest veterans deploy first, with a maximum of three per mission. Unselected soldiers remain in the barracks.
- **Permanent losses:** A dead soldier is removed from service immediately and recorded in the scrollable **LOST IN BATTLE** memorial, with their rank and mission number. A game crash/restart doesn't undo the death.
- **No soft lock:** A total squad wipeout authorizes three emergency recruits to retry the *current* mission, without restoring the fallen.
- **Barracks:** View surviving soldiers with ranks and missions served; swipe the list to view long rosters.
- **No level selection or replay:** Progress strictly from Operation 01 (**Jungle Assault**) to Operation 02 (**Depot Raid**). After finishing Operation 02 the camp shows **MISSION 03 — COMING SOON**, because a third mission hasn't yet been built.
- **Fresh v0.8 career:** Earlier prototype progress didn't store soldier identity, so v0.8 starts a new career instead of applying old stage-selection wins to the new permanent roster.

## Touch controls

Tap ground to move. Press-and-hold around 240 ms to shoot, drag to aim and release to stop. SPLIT separates Alpha/Bravo, tap team A/B to command independently, tap a soldier's name to control them individually, or hold the name to transfer teams. JOIN reunites them. FRAG arms grenades. Use PAUSE to suspend the operation.

## Technical notes

The playable game is self-contained in `index.html`, and an identical copy is packaged in the Android APK at `android/app/src/main/assets/index.html`. `.github/workflows/android-debug-apk.yml` builds and publishes a versioned GitHub Release. Local campaign state is stored in `green-dawn-campaign-v1`.

Android app ID: `uk.co.greendawn.jungle`, app version 0.8.0, min Android 8.0. No Internet permission, ads, accounts or tracking.
